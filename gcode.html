G-code reader: print time, filament used, and cost

Use this after you slice a model. Choose the G-code file and it reads the print time and filament used, then estimates the cost with your saved setup. The file stays in your browser and is never uploaded.

The file ends in .gcode. Not sure how to make one? See the steps below.

Then the weight is calculated from the length, the filament thickness, and the material's density. These are typical values, so check your spool.

How do I get a G-code file?

G-code is the instruction file your printer follows. You make it with a slicer, which is free software.

  1. Install a free slicer: UltiMaker Cura, PrusaSlicer, or OrcaSlicer. Download it from the official site.
  2. When it asks, add your printer by picking your model from the list. Your printer doesn't need to be connected.
  3. Open a model: File, then Open, then choose an .stl file. Free models are on sites like Printables, Thingiverse, and MakerWorld. A small calibration cube works well.
  4. Click Slice.
  5. Save the result. In Cura choose Save to Disk. In PrusaSlicer choose Export G-code. In OrcaSlicer choose Export G-code file. Button names vary a little by version. If you use a Bambu Lab printer, pick the plain G-code export, not the .3mf.

How it works

Slicers write summary totals into comment lines (lines starting with a semicolon), and each slicer words them a little differently. This tool reads those comments from PrusaSlicer, OrcaSlicer, Bambu Studio, and Cura files. Values it finds in the file are marked "read from file". If a file only gives filament length, the weight is worked out from the length and is marked "calculated".

Slicer estimates are usually close, but the real print time depends on your printer.
