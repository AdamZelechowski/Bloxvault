About BloxVault

BloxVault is a free set of 3D printing tools that share one saved setup: your printer, your filament, and your costs. Set them once, and every tool uses them, so you don't retype the same numbers on every page.

The tools currently available are:

  • Will it fit?, which checks whether a model fits your printer's bed at a given scale.
  • Enough filament?, which checks whether a spool has enough left for a print.
  • G-code reader, which reads the print time and filament used from a sliced file.
  • Print cost and pricing, which estimates what a print costs and what to charge for it.

All four tools run in your browser. An optional account lets you keep a profile, but nothing requires signing up.

BloxVault is an independent project and is not affiliated with any printer manufacturer, filament brand, or slicer developer named or implied on this site.
